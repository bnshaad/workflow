# Workflow Design Assets

This folder contains the approved UI for Workflow.

Priority:

1. project-knowledge-base (business and architecture)
2. DESIGN.md (design system)
3. screen.png (visual reference)
4. code.html (layout reference only)

Rules:

- Do not redesign the UI.
- Implement using React + TypeScript + Tailwind CSS + shadcn/ui.
- Reuse components across all screens.
- If implementation differs from the screenshots, follow the screenshots.
- If screenshots conflict with the knowledge base, the knowledge base takes precedence.
